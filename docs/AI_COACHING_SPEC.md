# AI_COACHING_SPEC.md - 牌読み分析 & AIコーチング仕様書

本ドキュメントでは、不完全情報（プレイヤー視点）からの牌読みロジック、LLM用プロンプト設計、およびローカルCLI（Antigravity CLI / Claude Code）連携仕様を定義します。

---

## 1. 牌読み分析のロジカルフレームワーク

AIコーチは、以下の麻雀理論・牌読みの原則に基づいて推論・解説を行います：

### (1) 現物（ゲンブツ）とフリテン
- リーチ者または特定相手がすでに河に捨てている牌は100%安全（同巡フリテン含む）。

### (2) 筋（スジ）の理論
- 両面待ち（リャンメン待ち）を想定した安全度分析。
- `4` が捨てられている場合 -> `1-7` がスジ（表スジ・裏スジ・中スジ・片スジ・モロスジの分類）。
- スジ牌の安全度とカンチャン・ペンチャン・単騎・シャンポン待ちへの警戒度を論理的に解説。

### (3) 壁（カベ）とノーチャンス / ワンチャンス
- 自分の手牌＋全員の捨て牌＋全員の副露＋ドラ表示牌の合計から、特定牌（例: `7m`）が4枚見えている場合：
  - `8m-9m` の両面待ちは存在し得ない（ノーチャンスによる `8m`, `9m` の外側安全牌）。
  - 3枚見えている場合はワンチャンス。

### (4) 序盤の捨て牌と手出し / ツモ切り
- 1〜4巡目に切られた数牌の外側（序盤の早切り牌の外側）の安全度比較。
- リーチ宣言牌およびその周辺牌、手出し後の打牌からターツ構成を推測。

### (5) 役・符計算・点数判断
- 現在の手牌から想定される役、アガリ時の符数（ツモ/ロン、待ちの形、雀頭、刻子）、翻数、点数（親/子、ツモ/ロン）の計算根拠を分かりやすく提示。

## 2. LLM向けプロンプトフォーマット設計

ゲームエンジンからローカルCLI（`agy` / `claude`）に送る局面テキストのテンプレート：

```markdown
あなたはプロの競技麻雀雀士であり、プレイヤーの専属AIコーチです。
提供された「プレイヤーから見える公開情報（自手牌・全員の河・副露・ドラ・点数状況）」のみを元に、論理的かつ分かりやすくプレイヤーの質問に答えてください。
※注意: 他家の非公開手牌や山牌の情報は伏せられており、あなたもプレイヤーと同じ不完全情報の中で牌読みと分析を行います。

## 現在の局面データ
{FORMATTED_GAME_CONTEXT}

## ユーザーからの質問
{USER_QUESTION}

## 回答方針
1. **結論を先に**: 何を切るべきか、どの牌が最も安全か、または点数の回答を端的に述べる。
2. **ロジカルな根拠**:
   - 筋（スジ）や壁（ノーチャンス/ワンチャンス）、現物に基づく危険度比較。
   - 自分の手のシャンテン数・受け入れ枚数・打点価値（符・翻計算）。
   - 押し引き（リーチ者の打点/速度と自分の手の価値の天秤）。
3. **上達へのアドバイス**: 次回以降も応用できる牌読みの着眼点を1行添える。
```

## 3. ローカルCLIブリッジの通信仕様

- **エンドポイント**: `POST /api/coach/chat`
- **リクエストペイロード**:
  ```json
  {
    "question": "対面のリーチに対して何を切れば安全ですか？",
    "context": { ...SanitizedPlayerView... },
    "cliBackend": "agy" // "agy" | "claude" | "mock"
  }
  ```
- **レスポンス**:
  ```json
  {
    "success": true,
    "reply": "結論として、現物である【三萬】またはノーチャンスの【九索】を切るのが安全です。...",
    "promptUsed": "...",
    "executionTimeMs": 1240
  }
  ```
